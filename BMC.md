## 6. SUMBER DAYA UTAMA

| Kategori | Sumber Daya                                           |
| -------- | ----------------------------------------------------- |
| Hardware | ESP8266, Panel P10, PCB custom, PSU 5V 10A, RTC       |
| Software | Firmware ESP8266, Web dashboard, Backend Node.js      |
| Cloud    | Railway, Netlify, HiveMQ                              |
| Manusia  | Developer, sales, dan support                         |
| Fisik    | Tempat produksi, stok komponen, demo unit             |

**Arsitektur Multi-Device:**

- Satu firmware untuk semua device, beda hanya device_uid dari chip ID ESP8266.
- Satu backend Railway melayani semua device.
- Satu database PostgreSQL, device = 1 baris di tabel devices.
- Tambah device baru cukup flash firmware yang sama.

## 11. RISIKO

| No | Risiko                         | Dampak                  | Mitigasi                                 |
| -- | ------------------------------ | ----------------------- | ---------------------------------------- |
| 1  | Customer tidak mau langganan   | Pendapatan berulang nol | Produk tetap jalan lokal tanpa server    |
| 2  | Trial Railway habis akhir Okt  | Server cloud mati       | ESP web server lokal tetap jalan         |
| 3  | Biaya server Rp 80.000/bulan   | Rugi jika 0 langganan   | Matikan server jika tidak ada yang bayar |
| 4  | Butuh kartu kredit             | Belum punya kartu       | Diskusi dengan orang tua                 |
| 5  | Margin tipis                   | Untung kecil / rugi     | Kontrol biaya, jual Rp 450.000           |
| 6  | Kompetitor impor lebih murah   | Sulit bersaing          | Tonjolkan kontrol HP + garansi lokal     |
| 7  | ESP server hanya WiFi sama     | Cloud jadi satu-satunya | Jual cloud sebagai fitur tambahan        |
| 8  | Trial tidak bisa dijeda        | Kredit hangus 30 hari   | Putuskan upgrade minggu ketiga Oktober   |
